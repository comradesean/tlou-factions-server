# NET_SM_ State Catalog (names only — pending confirmation)

38 distinct `NET_SM_*` names extracted from the binary's string table. Likely the client-side lobby/match state machine's state names (`game/net/lobby-flow.cpp`, `game/net/flow.cpp`) — e.g. `NET_SM_SERVER_LOBBY`, `NET_SM_READY_UP`, `NET_SM_LOAD_LEVEL`. Distinct from `NetEvent*` (see `netevent_catalog.md`), which look like the actual per-message wire opcodes; these look more like macro state IDs for the match flow, though transitions between them are plausibly synced over the network too. Unconfirmed either way — full raw list: `research/notes/net_sm_states.txt`.
